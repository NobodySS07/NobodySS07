### What I work on

- **LLM evaluation:** LLM-as-judge evaluators calibrated against human labels (0.82 Cohen's kappa), rubric design, agreement statistics
- **Speech and voice:** STT benchmarking (WER, timestamp drift), multi-channel transcription, speaker attribution in multi-party recordings
- **Retrieval:** embedding search and near-duplicate detection with PostgreSQL / pgvector
- **Human-in-the-loop data pipelines:** quality gates, idempotent exports, and automated rework for AI training data

### Work highlights

These are client projects, so the code is private; the numbers are real.

| Project | What it does | Result |
|---|---|---|
| Calling data pipeline | Twilio + n8n pipeline capturing scripted business calls as dual-channel audio, transcripts and rubric-scored outcomes for training AI agents | 228 calls, 100% QC, delivered in 8 days |
| Multi-party recording platform | Zoom Video SDK meetings turned into reviewed, speaker-attributed transcripts by matching unnamed audio tracks to active-speaker events | 254 automated tests |
| Translation review round trip | Machine-translated voice-assistant data reviewed in 20+ locales and written back byte-identical to the client's files | 177 automated tests |
| LLM-as-judge evaluator | Decomposed-rubric judge for QC, calibrated against 100 human-adjudicated cases | QC time cut 72% |
| STT provider benchmark | 3 providers, 5 locales, semantic error separated from formatting | 92.5% raw WER shown to be 6.6% true error; throughput up 5-6x |
| Translation memory retrieval | Embedding retrieval on AlloyDB (pgvector) reusing approved translations | $32K saved per month |

Earlier at **o9 Solutions**: fine-tuned RoBERTa for data imputation and deployed anomaly detection across 90,000+ demand time series.
